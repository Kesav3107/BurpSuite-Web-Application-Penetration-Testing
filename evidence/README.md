# Evidence

This folder contains practical evidence from the Burp Suite Web Application Penetration Testing project using the OWASP Juice Shop local laboratory.

## Evidence Included

- Docker environment setup
- OWASP Juice Shop application baseline
- Burp Suite Proxy configuration
- Firefox proxy configuration
- HTTP request interception
- Authentication testing
- Burp Repeater testing
- Burp Intruder testing
- API authorization testing
- Object-level authorization testing
- Session and token analysis
- XSS-oriented testing
- CSRF/session-security analysis
